CO2 Emission Prediction using Machine Learning

Developed a machine learning based system to estimate CO₂ emissions using Air Quality Index (AQI) data. The project involved data collection, preprocessing, and applying machine learning algorithms such as Linear Regression and Random Forest to predict emission levels. A web interface was created using Flask and Streamlit to allow users to input data and visualize prediction results using interactive graphs.

IoT Voice-Assisted Smart Charger

Developed an IoT-enabled smart charger that provides voice notifications for charging updates such as battery full, low battery, and abnormal power conditions. The system allows users to monitor charging status remotely using IoT communication protocols and embedded programming to improve device safety and user convenience.
